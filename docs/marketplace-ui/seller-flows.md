# Seller Flows

UI workflows for skill sellers.

## Create listing

1. **Upload** — drag-and-drop or file picker for skill package
2. **Validate** — show validation progress and errors inline
3. **Metadata** — name, description, category, version, evaluation type
4. **Pricing** — set price, trial policy (if any)
5. **Publish** — confirm and go live

## Manage listings

- Edit metadata (creates new version if skill package changed)
- Unpublish / republish
- View purchase history

## Post-purchase

- View credited balance from successful evaluations
- No access to buyer datasets or evaluation details beyond aggregate stats
