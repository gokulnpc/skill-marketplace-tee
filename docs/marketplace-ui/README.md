# Marketplace UI

Next.js web application for sellers and buyers.

## Planned location

`apps/web/`

## Seller surfaces

- Upload skill package
- Edit listing metadata
- Set price and publish
- View purchases and payout status

See [seller-flows.md](seller-flows.md).

## Buyer surfaces

- Browse and search skill listings
- Select skill and set threshold
- Launch buyer CLI instructions / connect flow
- View TEE attestation proof
- Scorecard after evaluation
- Payment and license status

See [buyer-scorecard.md](buyer-scorecard.md).
